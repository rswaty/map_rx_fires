# Put your burn CSV here

1. Make a CSV like [`template.csv`](../template.csv): one row per burn, **5 burns at most**.
2. On this page click **Add file → Upload files**, add your CSV, pick
   **Create a new branch**, and click **Commit changes** (then **Propose changes** is optional).
3. Open the **Actions** tab. Your run takes about 4 minutes per burn.
4. When it shows a green check, open the run and download **burn-maps** at the bottom.

Full instructions: [main README](../README.md).
